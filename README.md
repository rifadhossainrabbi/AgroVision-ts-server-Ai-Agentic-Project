# AgroVision Server (TypeScript)

This repository contains the AgroVision backend API built with Express,
TypeScript, MongoDB, and AI integrations.

## Scripts

- `npm run dev` — start the server in development mode with nodemon
- `npm run build` — compile the TypeScript source to the `dist` folder
- `npm start` — run the compiled server from `dist`

## Environment variables

Copy `.env.example` to `.env` and fill in the required values before running the
server.
